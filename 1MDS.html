Máterias Técnicas do 1MDS



A disciplina Programação Web I é um dos pilares fundamentais para quem deseja ingressar no mundo do desenvolvimento de sistemas para a web. Nela, você aprenderá os conceitos básicos e as tecnologias essenciais para criar páginas e aplicações que funcionam diretamente no navegador.

O que você vai estudar?
- HTML: A estrutura básica de qualquer página web. Você aprenderá a criar elementos como textos, imagens, links e tabelas, organizando o conteúdo de forma semântica e acessível.
- CSS: A linguagem responsável pelo estilo e design das páginas. Com ela, você poderá personalizar cores, fontes, layouts e até criar animações simples, tornando suas páginas mais atraentes e funcionais.
- JavaScript: A linguagem de programação que adiciona interatividade às páginas. Você verá como manipular elementos HTML, responder a eventos (como cliques de mouse) e criar lógica para tornar suas páginas dinâmicas.
- Noções de responsividade: Como adaptar suas páginas para diferentes dispositivos, como celulares, tablets e desktops, garantindo uma experiência agradável para todos os usuários.
Por que essa disciplina é importante?
A programação web está presente em quase todos os aspectos da internet. Desde sites institucionais até aplicações complexas como redes sociais e e-commerces, o conhecimento em HTML, CSS e JavaScript é a base para construir soluções modernas e escaláveis. Além disso, essas habilidades são altamente valorizadas no mercado de trabalho, abrindo portas para carreiras em desenvolvimento front-end, back-end e full-stack.

O que você será capaz de fazer ao final do curso?
- Ao concluir a disciplina, você estará apto a:

- Criar páginas web estáticas e dinâmicas.
- Estruturar e estilizar conteúdos de forma profissional.
- Adicionar interatividade básica às suas páginas.
- Entender como as tecnologias web se integram para criar experiências ricas e funcionais.
- Programação Web I é apenas o começo de uma jornada empolgante no desenvolvimento web. Com dedicação e prática, você estará pronto para explorar tecnologias mais avançadas e construir projetos cada vez mais incríveis!


A disciplina Sistemas Embarcados I é o primeiro passo para entender como os dispositivos eletrônicos ao nosso redor — como smartphones, eletrodomésticos, carros, sistemas de segurança e até mesmo equipamentos médicos — funcionam por dentro. Esses sistemas são chamados de “embarcados” porque são integrados diretamente ao hardware, executando tarefas específicas com eficiência e precisão.

O que você vai estudar?
- Microcontroladores e Microprocessadores: Você conhecerá os componentes principais que dão “vida” aos sistemas embarcados, como o Arduino, Raspberry Pi e outros. Aprenderá como eles processam informações e controlam dispositivos físicos.
- Linguagem C: A linguagem mais usada em sistemas embarcados. Com ela, você escreverá códigos otimizados para interagir diretamente com o hardware, controlando sensores, motores e displays.
- Interfacing com Hardware: Como conectar e controlar componentes externos, como LEDs, botões, sensores de temperatura, motores e comunicação serial (UART, I2C, SPI). Você aprenderá a ler dados de sensores e enviar comandos para atuadores.
- Noções de Eletrônica Básica: Conceitos essenciais para entender como os circuitos funcionam, como tensão, corrente, resistores, capacitores e transistores. Isso ajudará você a projetar e depurar seus próprios circuitos.
- Depuração e Teste: Técnicas para identificar e corrigir erros em seus projetos, garantindo que tudo funcione como esperado.
Por que essa disciplina é importante?
Os sistemas embarcados estão em todo lugar e são a base da Internet das Coisas (IoT), automação residencial, indústria 4.0, veículos autônomos e muito mais. Dominar essa área abre portas para carreiras em engenharia de software, engenharia elétrica, robótica e automação. Além disso, é um campo onde você pode transformar ideias em projetos reais, como um sistema de irrigação automática ou um robô controlado por voz.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Desenvolver programas em C para microcontroladores.
- Projetar e montar circuitos simples para interagir com hardware.
- Ler dados de sensores e controlar atuadores (como motores e LEDs).
- Depurar e corrigir problemas em seus projetos.
- Criar soluções práticas para problemas do dia a dia usando sistemas embarcados.
Sistemas Embarcados I é apenas o começo de uma jornada fascinante no mundo da eletrônica e programação de baixo nível. Com criatividade e prática, você poderá construir projetos incríveis e até mesmo contribuir para a inovação tecnológica!


A disciplina Computação em Nuvem I é o ponto de partida para entender como a tecnologia que move grande parte da internet funciona nos bastidores. A computação em nuvem permite que empresas, desenvolvedores e até mesmo usuários finais acessem recursos computacionais — como armazenamento, processamento e softwares — de forma flexível, escalável e sob demanda, sem a necessidade de investir em infraestrutura física própria.

O que você vai estudar?
- Conceitos Fundamentais da Nuvem: Você aprenderá o que é a computação em nuvem, seus modelos de serviço (IaaS, PaaS, SaaS) e os tipos de nuvem (pública, privada, híbrida).
- Provedores de Nuvem: Conhecerá os principais serviços da AWS (Amazon Web Services), Microsoft Azure e Google Cloud Platform, descobrindo como eles oferecem soluções para armazenamento, hospedagem de aplicativos, bancos de dados e muito mais.
- Virtualização e Contêineres: Tecnologias como máquinas virtuais (VMs) e Docker que permitem criar ambientes isolados e escaláveis, otimizando o uso de recursos.
- Armazenamento em Nuvem: Como funciona o armazenamento distribuído, com exemplos práticos de serviços como Amazon S3, Azure Blob Storage e Google Drive.
- Segurança na Nuvem: Noções básicas de como proteger dados e aplicações na nuvem, incluindo criptografia, autenticação e boas práticas de gestão de identidade.
- Implantação de Aplicações: Passos para subir um site, uma API ou um banco de dados na nuvem, utilizando serviços como AWS EC2, Azure App Service e Google App Engine.
Por que essa disciplina é importante?
A computação em nuvem revolucionou a forma como empresas e indivíduos lidam com tecnologia. Ela permite reduzir custos, aumentar a eficiência, melhorar a colaboração e escalar soluções de forma quase ilimitada. Hoje, desde startups até gigantes como Netflix e Spotify dependem da nuvem para operar. Dominar essa área é essencial para quem quer trabalhar com desenvolvimento de software, DevOps, segurança da informação ou gestão de infraestrutura.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Entender os conceitos e modelos da computação em nuvem.
- Criar e gerenciar máquinas virtuais e contêineres.
- Armazenar e recuperar dados de forma segura na nuvem.
- Implantar aplicações simples em ambientes de nuvem.
- Aplicar boas práticas de segurança em projetos na nuvem.
Computação em Nuvem I é apenas o início de uma jornada repleta de possibilidades. Com essa base, você poderá explorar tecnologias avançadas, como machine learning na nuvem, big data e IoT, e se tornar um profissional capaz de transformar ideias em soluções escaláveis e inovadoras!


A disciplina Banco de Dados I é essencial para quem deseja entender como os sistemas armazenam, organizam e gerenciam informações de forma eficiente e segura. Bancos de dados são a base de quase todos os aplicativos modernos, desde redes sociais até sistemas bancários, passando por e-commerces e aplicações governamentais. Nesta disciplina, você aprenderá os conceitos fundamentais para projetar e manipular bancos de dados, garantindo que as informações estejam sempre acessíveis, organizadas e protegidas.

O que você vai estudar?
- Conceitos Básicos de Bancos de Dados: Você entenderá o que é um banco de dados, como ele funciona e qual a diferença entre bancos de dados relacionais e não relacionais.
- Modelagem de Dados: Aprenderá a projetar um banco de dados usando o modelo entidade-relacionamento (ER), criando diagramas que representam as relações entre tabelas, como chaves primárias, chaves estrangeiras e normalização.
- SQL (Structured Query Language): A linguagem padrão para manipular bancos de dados. Você verá como criar tabelas, inserir, atualizar e excluir dados, além de realizar consultas complexas com SELECT, JOIN, GROUP BY e subqueries.
- Sistemas Gerenciadores de Bancos de Dados (SGBDs): Conhecerá ferramentas como MySQL, PostgreSQL e SQLite, aprendendo a instalá-las e utilizá-las para gerenciar seus bancos de dados.
- Integridade e Segurança de Dados: Noções básicas de como garantir que os dados estejam corretos e seguros, incluindo restrições de integridade, transações e controle de acesso.
- Backup e Recuperação: Técnicas para proteger seus dados, garantindo que eles possam ser recuperados em caso de falhas ou erros.
Por que essa disciplina é importante?
Os bancos de dados são o coração de qualquer sistema que lida com informações. Eles permitem que empresas tomem decisões baseadas em dados, que aplicativos funcionem de forma rápida e confiável, e que informações críticas sejam armazenadas com segurança. Dominar essa área é fundamental para carreiras em desenvolvimento de software, análise de dados, gestão de TI e ciência de dados. Além disso, é uma habilidade que pode ser aplicada em projetos pessoais, como criar um sistema de controle de estoque ou uma plataforma de gerenciamento de tarefas.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Projetar um banco de dados relacional usando modelagem ER.
- Criar e manipular tabelas usando SQL.
- Realizar consultas avançadas para extrair informações úteis dos dados.
- Garantir a integridade e segurança dos dados armazenados.
- backup e recuperar dados em caso de falhas.
- Aplicar conceitos de normalização para evitar redundâncias e inconsistências.
Banco de Dados I é apenas o começo de uma jornada incrível no mundo da gestão de informações. Com essa base, você poderá explorar tecnologias avançadas, como bancos de dados NoSQL, big data e data warehousing, e se tornar um profissional capaz de transformar dados em insights valiosos!


A disciplina Projetos de Tecnologia, Informação e Comunicação (PTIC) é o espaço onde a teoria e a prática se encontram para criar soluções inovadoras que integram tecnologia, gestão de informações e comunicação. Neste curso, você aprenderá a desenvolver projetos reais, desde a concepção até a implementação, aplicando conceitos de diversas áreas para resolver problemas do mundo atual. Seja criando um aplicativo, um sistema de gestão, uma campanha de comunicação digital ou uma solução de automação, o PTIC é o laboratório onde você colocará suas habilidades em ação.

O que você vai estudar?
- Metodologias de Desenvolvimento de Projetos: Você conhecerá abordagens como Scrum, Kanban e Design Thinking, que ajudam a organizar, planejar e executar projetos de forma eficiente e colaborativa.
- Gestão de Projetos: Aprenderá a definir objetivos, escopo, cronograma, orçamento e recursos, além de ferramentas como diagrama de Gantt, mapas mentais e SWOT para acompanhar o progresso e garantir o sucesso do projeto.
- Integração de Tecnologias: Como combinar diferentes tecnologias — como bancos de dados, ** APIs**, sistemas embarcados e plataformas de nuvem — para criar soluções completas e funcionais.
- Comunicação e Colaboração: Técnicas para trabalhar em equipe, apresentar ideias de forma clara e persuasiva, e comunicar resultados para diferentes públicos, desde clientes até colegas de equipe.
- Sustentabilidade e Ética em Projetos: Como considerar o impacto social, ambiental e ético de seus projetos, garantindo que eles sejam responsáveis e alinhados com as necessidades da sociedade.
- Documentação e Apresentação: A importância de documentar cada etapa do projeto e apresentar resultados de forma profissional, seja por meio de relatórios, protótipos ou demonstrações.
Por que essa disciplina é importante?
Os projetos de tecnologia, informação e comunicação estão por trás de grande parte das inovações que moldam nosso dia a dia. Eles permitem que empresas otimizem processos, que governos ofereçam serviços mais eficientes, que organizações sem fins lucrativos ampliem seu alcance e que startups criem soluções disruptivas. Além disso, desenvolver habilidades em gestão de projetos é fundamental para qualquer profissional que queira se destacar no mercado, seja como desenvolvedor, analista, empreendedor ou líder de equipe.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Planejar e executar projetos do zero, aplicando metodologias ágeis e tradicionais.
- Integrar diferentes tecnologias para criar soluções completas e funcionais.
- Trabalhar em equipe de forma colaborativa e eficiente.
- Comunicar ideias e resultados de forma clara e persuasiva.
- Considerar aspectos éticos, sociais e ambientais em seus projetos.
- Documentar e apresentar projetos de forma profissional.
Projetos de Tecnologia, Informação e Comunicação (PTIC) é uma disciplina que vai além da sala de aula. É uma oportunidade de colocar suas habilidades em prática, desenvolver sua criatividade e inovar. Com dedicação e paixão, você poderá criar projetos que façam a diferença no mundo!


A disciplina Programação de Algoritmos é a base de toda a programação. Aqui, você aprenderá a pensar de forma estruturada e lógica para resolver problemas, criando sequências de passos (algoritmos) que um computador possa executar. É como ensinar um robô a tomar decisões inteligentes! Nesta disciplina, você descobrirá que a programação não é apenas sobre escrever código, mas sobre entender problemas, quebrá-los em partes menores e construir soluções eficientes. Seja para ordenar uma lista, buscar informações ou otimizar processos, os algoritmos são a chave para transformar ideias em realidade.

O que você vai estudar?
- Conceitos Fundamentais de Algoritmos: Você aprenderá o que é um algoritmo, como representá-lo (usando fluxogramas ou pseudocódigo) e como avaliar sua eficiência com complexidade de tempo e espaço (Big-O).
- Estruturas de Controle: Como usar condicionais (if/else), laços (for, while) e estruturas de repetição para controlar o fluxo de um programa.
- Estruturas de Dados Básicas: Aprenderá a trabalhar com variáveis, vetores (arrays), matrizes, listas, pilhas e filas, que são essenciais para organizar e manipular dados.
- Algoritmos de Busca e Ordenação: Técnicas como busca linear, busca binária, bubble sort, insertion sort e merge sort, que são fundamentais para manipular dados de forma eficiente.
- Recursividade: Como resolver problemas dividindo-os em subproblemas menores, usando funções que chamam a si mesmas (ex.: calcular fatorial, sequência de Fibonacci).
- Resolução de Problemas: Exercícios práticos para aplicar o que você aprendeu, desenvolvendo a habilidade de transformar problemas do mundo real em algoritmos.
Por que essa disciplina é importante?
Os algoritmos estão por trás de tudo o que fazemos na programação. Eles são a base para criar softwares, aplicativos, jogos, sistemas de inteligência artificial e muito mais. Dominar essa disciplina significa desenvolver pensamento computacional, uma habilidade valiosa não só para programadores, mas para qualquer profissional que queira resolver problemas de forma estruturada. Além disso, entender algoritmos ajuda a escrever código mais rápido, eficiente e escalável.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Criar algoritmos claros e eficientes para resolver problemas.
- Representar algoritmos usando fluxogramas e pseudocódigo.
- Implementar estruturas de controle e estruturas de dados em linguagens de programação.
- Analisar a eficiência de um algoritmo usando conceitos de complexidade.
- Aplicar técnicas de busca, ordenação e recursividade em projetos reais.
- Desenvolver o raciocínio lógico necessário para enfrentar desafios de programação.
Programação de Algoritmos é como aprender a escrever a “receita” por trás de qualquer programa. Com essa base sólida, você estará pronto para explorar linguagens de programação, frameworks e tecnologias avançadas, e se tornar um desenvolvedor capaz de criar soluções inteligentes e inovadoras!


A disciplina Projeto de Desenvolvimento de Sistemas (PDS) é onde a teoria se transforma em prática. Neste curso, você colocará em ação tudo o que aprendeu ao longo do curso técnico: desde a análise de requisitos até a implementação de um sistema completo. PDS é sobre criar soluções tecnológicas que resolvam problemas reais, seja para empresas, usuários finais ou até mesmo para projetos pessoais. Você aprenderá a trabalhar em equipe, a gerenciar prazos e a entregar um produto funcional, documentado e pronto para uso. É o momento de exercitar sua criatividade, sua capacidade de resolver problemas e sua habilidade de transformar ideias em realidade.

O que você vai estudar?
- Análise de Requisitos: Como identificar e documentar as necessidades do cliente ou usuário, transformando-as em especificações técnicas claras. Você aprenderá a usar técnicas como entrevistas, questionários e casos de uso para entender o que o sistema deve fazer.
- Modelagem de Sistemas: Ferramentas como diagramas de classes (UML), diagramas de sequência e diagramas de atividade para projetar a estrutura e o comportamento do sistema antes de começar a codificar.
- Arquitetura de Software: Como escolher a melhor arquitetura para o seu projeto, seja monolítica, baseada em microsserviços ou em camadas, levando em conta escalabilidade, segurança e manutenibilidade.
- Desenvolvimento Iterativo e Incremental: Metodologias como Scrum ou Kanban para dividir o projeto em etapas (sprints), permitindo feedback contínuo e ajustes ao longo do caminho.
- Implementação e Codificação: Aplicar linguagens de programação, frameworks e tecnologias para construir o sistema. Você trabalhará com bancos de dados, interfaces de usuário, lógicas de negócio e integrações (como APIs ou sistemas externos).
- Testes e Qualidade de Software: Como garantir que o sistema funcione corretamente, usando técnicas de testes unitários, testes de integração, testes de usabilidade e testes de aceitação.
- Documentação: A importância de documentar o sistema para facilitar a manutenção, o uso e futuras atualizações. Isso inclui manuais de usuário, documentação técnica e relatórios de projeto.
- Implantação e Entrega: Como preparar o sistema para ser implantado em um ambiente real, seja em um servidor local, na nuvem ou em dispositivos específicos. Você também aprenderá a fazer a entrega ao cliente e a treinar usuários finais.
Por que essa disciplina é importante?
Desenvolver um sistema do zero é um desafio que exige planejamento, organização e trabalho em equipe. PDS é a disciplina que simula esse processo, preparando você para o mercado de trabalho. Aqui, você aprenderá a lidar com imprevistos, a tomar decisões técnicas e a comunicar suas ideias de forma clara. Além disso, projetos bem-sucedidos de PDS podem se tornar portfólio, ajudando você a se destacar em processos seletivos ou até mesmo a empreender.

O que você será capaz de fazer ao final do curso?
Ao concluir a disciplina, você estará apto a:

- Analisar requisitos e transformá-los em um projeto técnico viável.
- Modelar sistemas usando UML e outras ferramentas.
- Desenvolver um sistema completo, do banco de dados à interface do usuário.
- Trabalhar em equipe, gerenciando prazos e responsabilidades.
- Testar e garantir a qualidade do software antes da entrega.
- Documentar e implantar o sistema de forma profissional.
- Apresentar o projeto para clientes ou avaliadores, defendendo suas escolhas técnicas.
Projeto de Desenvolvimento de Sistemas (PDS) é a disciplina que fecha o ciclo do seu aprendizado técnico. É o momento de colocar a mão na massa, de errar, de aprender e de criar algo tangível que você possa orgulhosamente mostrar para o mundo. Com dedicação e paixão, você estará pronto para ingressar no mercado de trabalho ou até mesmo iniciar seus próprios projetos!
